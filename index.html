El Teorema de Zeckendorf i les Monedes de Fibonàcia

Què diu el Teorema de Zeckendorf?

Tot nombre enter positiu es pot representar de manera ÚNICA com a suma d'un o més nombres de Fibonacci no consecutius ($1, 2, 3, 5, 8, 13, 21...$).

Per què usem aquestes dues regles al poble?

  • Sense repetir moneda: Si repetim ($1+1=2$ o $3+3=6$), la representació deixa de ser única.
  • Mai monedes veïnes: Dos nombres consecutius de Fibonacci es sumen per donar el següent ($2+3=5$). Per tant, tenir $2$ i $3$ és redundant perquè és millor usar el $5$ directament!

El secret de les Targetes Màgiques

Al sistema decimal comptem amb base 10 ($1, 10, 100...$). En el sistema binari comptem amb potències de 2 ($1, 2, 4, 8, 16...$).

El **Sistema de Zeckendorf** ens permet escriure qualsevol nombre utilitzant els nombres de Fibonacci com a "base". Cada targeta (A, B, C, D, E) correspon a un nombre base de Fibonacci ($1, 2, 3, 5, 8$). Quan la persona diu que SÍ, només sumem el nombre base d'aquella targeta!

Exemple (Nombre 19):
19 = 13 + 5 + 1 (Sense veïns: 13, 5, 1)
Surt a la Targeta A (+1), Targeta D (+5) i Targeta F (+13).
